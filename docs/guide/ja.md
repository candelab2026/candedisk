# CandeDisk ガイド

CandeDisk は Windows 用のディスク・パーティション管理ツールです。ディスクを表示し、シンプルな画面からパーティションのフォーマット、作成、削除、サイズ変更ができます。

> ディスク操作はデータを完全に消去します。続行する前に必ずバックアップを取ってください。

## はじめに

- CandeDisk を起動します。ディスクを変更するには**管理者**権限が必要です。Release 版は自動的に権限を要求します (UAC の画面)。
- 権限なしで起動した場合は、黄色のバナーが表示され、**読み取り専用**モードで動作します。**管理者として再起動**ボタンで、必要な権限で開き直せます。
- 左側にディスクの一覧、右側に選択したディスクのマップとパーティションの表が表示されます。
- 言語を変えるには**言語**メニューを使います。変更はすぐに反映され、記憶されます。

## ディスクマップ

色付きのバーは、各パーティションをサイズの比率で表示します。非常に小さいパーティション (EFI、MSR) は、クリックできるように最小幅が確保されています。

- **青:** Windows のパーティション。
- **琥珀色:** 特殊なパーティション (EFI、回復、予約)。
- **緑:** データ用のパーティション。
- **灰色:** 未割り当て領域。

ボックスをクリックすると、表の対応するパーティションが選択されます。

## 操作

### 初期化

新しいディスクは「RAW」と表示され、パーティションテーブルがありません。**初期化**は **GPT** テーブルで準備します。RAW ディスクでのみ有効です。

### パーティションの作成

1. **未割り当て**の行を選択します。
2. **作成** (`Ctrl+N`) を押します。
3. サイズ (MB)、ファイルシステム、ラベルを選びます。最大サイズを選ぶと、Windows は実際に使える領域をすべて使います。

### フォーマット

1. パーティションを選択して**フォーマット** (`Ctrl+Shift+F`) を押します。
2. ファイルシステム (NTFS、exFAT、FAT32) とラベルを選びます。
3. **クイックフォーマット**を推奨します。完全フォーマットはボリューム全体に書き込むため、はるかに時間がかかります。

**パーティション内のすべてのデータが消去されます。**

### サイズ変更

1. パーティションを選択して**サイズ変更** (`Ctrl+R`) を押します。
2. CandeDisk は Windows に対応する最小・最大サイズを問い合わせ、表示します。
3. 新しいサイズ (MB) を入力します。

パーティションを**拡張**するには、その**直後**に未割り当て領域が必要です。間に別のパーティションがあると、Windows は拡張を許可しません。**縮小**できるのは、データが使用している領域までです。

### 削除

パーティションを選択して**削除** (`Del`、表にフォーカスがある状態) を押します。ディスクの管理では削除できない保護されたパーティション (EFI、OEM、回復) は、追加の確認のあと、`diskpart` の「override」モードで削除されます。

## 保護機能

CandeDisk は、重大な操作ミスを防ぐようにしています。

- 実行中の Windows のパーティション、システムドライブ、起動に使っているディスクの EFI パーティションは、**フォーマットも削除もできません**。
- データを消去する操作では、ディスク名を表示した**二重の確認**があり、特殊なパーティションやシステムディスクでは 3 回目の確認があります。
- **オフライン**または**読み取り専用**のディスクは変更されません。
- ラベルとファイルシステムは、Windows に渡す前に検証されます。

## キーボードショートカット

- `F5`: ディスク一覧を更新
- `F1`: このガイドを開く
- `Ctrl+N`: パーティションを作成
- `Ctrl+Shift+F`: フォーマット
- `Ctrl+R`: サイズ変更
- `Del`: 削除 (表にフォーカスがある状態)

## 操作ログ

すべての操作 (開始、結果、発生したエラー) はテキストファイルに記録されます。**ヘルプ > ログフォルダーを開く**からフォルダーを開けます。ファイルは `%LocalAppData%\CandeDisk\logs` にあります。

## 概要のコピー

**ファイル > ディスクの概要をコピー**で、ディスクとパーティションの一覧がテキストでクリップボードに入ります。問題を報告するときに便利です。

## よくある質問

- **ディスクが表示されません。** **更新**を押してください。オフラインのディスクは、Windows のディスクの管理でオンラインにする必要があります。
- **ボタンが灰色です。** プログラムが読み取り専用です (管理者として再起動してください)。または、操作に適したパーティションや未割り当て領域を選択していません。
- **パーティションを拡張できません。** 直後 (右側) に未割り当て領域が必要です。CandeDisk はパーティションを移動しません。
- **「Not enough available capacity」と表示されます。** Windows が連続した十分な領域を見つけられませんでした。少し小さいサイズにするか、最大サイズを使ってください。
- **2 つのパーティションを結合できますか?** 直接はできません。隣り合っている場合は、2 つ目を削除して (データを保存してから) 1 つ目を拡張します。

## 既知の制限

- パーティションの**移動**には対応していません。
- 対応するファイルシステムは **NTFS、exFAT、FAT32** です。
- ダイナミックディスクとソフトウェア RAID の構成は扱えません。
