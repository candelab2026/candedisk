# CandeDisk 使用指南

CandeDisk 是适用于 Windows 的磁盘和分区管理器：它会显示你的磁盘，并通过简单的界面格式化、创建、删除和调整分区大小。

> 磁盘操作会永久删除数据。继续之前请务必备份。

## 开始使用

- 启动 CandeDisk。修改磁盘需要**管理员**权限：Release 版本会自动请求权限（UAC 窗口）。
- 如果程序在没有权限的情况下启动，会显示黄色横幅并以**只读**模式运行。点击**以管理员身份重新启动**按钮，即可用所需权限重新打开。
- 左侧是磁盘列表，右侧是所选磁盘的示意图和分区表。
- 要切换语言，请使用**语言**菜单：切换立即生效，并且会被记住。

## 磁盘示意图

彩色条按大小比例显示每个分区。非常小的分区（EFI、MSR）有最小宽度，以便仍然可以点击。

- **蓝色：**Windows 分区。
- **琥珀色：**特殊分区（EFI、恢复、保留）。
- **绿色：**数据分区。
- **灰色：**未分配空间。

点击某个方块，即可在表格中选中对应的分区。

## 操作

### 初始化

新磁盘会显示为“RAW”，没有分区表。**初始化**会为它建立 **GPT** 分区表，仅对 RAW 磁盘可用。

### 创建分区

1. 选择一行**未分配**。
2. 点击**创建**（`Ctrl+N`）。
3. 选择大小（MB）、文件系统和卷标。如果选择最大大小，Windows 会使用实际可用的全部空间。

### 格式化

1. 选择分区并点击**格式化**（`Ctrl+Shift+F`）。
2. 选择文件系统（NTFS、exFAT 或 FAT32）和卷标。
3. 推荐使用**快速格式化**。完整格式化会写入整个卷，速度慢得多。

**分区上的所有数据都会被清除。**

### 调整大小

1. 选择分区并点击**调整大小**（`Ctrl+R`）。
2. CandeDisk 会向 Windows 查询支持的最小和最大大小并显示给你。
3. 输入新的大小（MB）。

要**扩展**分区，它的**后面紧邻**必须有未分配空间：如果中间隔着其他分区，Windows 不允许扩展。**缩小**分区时，最多只能缩小到数据实际占用的空间。

### 删除

选择分区并点击**删除**（`Del`，焦点需在表格上）。“磁盘管理”拒绝删除的受保护分区（EFI、OEM、恢复），会在额外确认后通过 `diskpart` 的“override”模式移除。

## 保护措施

CandeDisk 会尽力防止最严重的错误：

- 你**无法格式化或删除**正在运行的 Windows 分区、系统驱动器，以及你用来启动电脑的磁盘上的 EFI 分区。
- 每个会清除数据的操作都需要带磁盘名称的**两次确认**；特殊分区或系统磁盘上的操作还需第三次确认。
- **脱机**或**只读**的磁盘不会被修改。
- 卷标和文件系统在传给 Windows 之前会先经过验证。

## 键盘快捷键

- `F5`：刷新磁盘列表
- `F1`：打开本指南
- `Ctrl+N`：创建分区
- `Ctrl+Shift+F`：格式化
- `Ctrl+R`：调整大小
- `Del`：删除（焦点需在表格上）

## 操作日志

每次操作（开始、结果以及可能的错误）都会记录在文本文件中。通过**帮助 > 打开日志文件夹**打开该文件夹。文件位于 `%LocalAppData%\CandeDisk\logs`。

## 复制摘要

**文件 > 复制磁盘摘要**会把磁盘和分区的文本列表放入剪贴板，便于报告问题。

## 常见问题

- **看不到我的磁盘。**点击**刷新**。脱机的磁盘需要在 Windows“磁盘管理”中联机。
- **按钮是灰色的。**程序处于只读模式（请以管理员身份重新启动），或者你没有选择适合该操作的分区或未分配空间。
- **无法扩展分区。**它的右侧紧邻处需要有未分配空间。CandeDisk 不会移动分区。
- **出现“Not enough available capacity”。**Windows 没有找到足够的连续空间：请选择稍小一点的大小，或使用最大大小。
- **可以合并两个分区吗？**不能直接合并：先删除第二个分区（保存好数据之后），再扩展第一个分区（前提是它们相邻）。

## 已知限制

- 不支持**移动**分区。
- 支持的文件系统为 **NTFS、exFAT 和 FAT32**。
- 不处理动态磁盘和软件 RAID 配置。
